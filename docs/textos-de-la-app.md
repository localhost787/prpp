# Todos los textos de la app, en español sencillo (ítem 17)
Es un documento de texto, no código. En el evento, el agente copia estos textos tal cual. **Regla:** frases cortas, "usted", sin siglas; cada resultado dice qué es, si está bien o no y "pregúntele a su equipo si tiene dudas".

**Para probar con una persona mayor (ítem 18):** leerle la columna "Texto" y marcar si lo entendió.

## Etapas de la visita
| Etapa | Texto | ¿Entendió? |
|---|---|---|
| Llegada | "Llegó a Emergencias. Su registro está completo." | |
| Triaje | "La enfermera la clasificó. Nivel {n} de 5." | |
| En espera | "Está en la fila. Se atiende por gravedad, no por orden de llegada." | |
| En evaluación | "La llamaron al cubículo {n}. La atiende {médico}." | |
| Estudios | "Le están haciendo estudios. Los resultados le llegarán aquí." | |
| Decisión | "Su médica está decidiendo si se va a casa o se queda." | |
| Alta | "Le dieron de alta. Sus instrucciones están en 'Mi cuidado'." | |
| Ingreso | "La van a ingresar. Cuarto {n}." | |

## Estado de cada estudio
| Estado | Texto corto | Explicación |
|---|---|---|
| Ordenado | "Ordenado" | "Su médica pidió este estudio." |
| Muestra tomada | "Muestra tomada" | "Ya le sacaron la muestra. Va para el laboratorio." |
| En proceso | "En proceso" | "El laboratorio lo está analizando." |
| Preliminar | "Preliminar" | "Hay un primer resultado. Puede cambiar cuando lo confirmen." |
| Listo | "Listo" | "El resultado está completo." |
| Corregido | "Corregido" | "El laboratorio corrigió este resultado. Mire el valor nuevo." |

## Avisos importantes
| Cuándo | Texto |
|---|---|
| Llega un resultado | "Resultado listo: {estudio}." |
| Siempre en Resultados | "Los resultados le llegan al mismo tiempo que a su equipo. Es posible que su médica aún no los haya revisado. Si tiene dudas, pregúntele." |
| Resultado crítico | "Hay un resultado importante. Su equipo ya fue avisado y la va a atender." (**nunca** mostrar el valor solo) |
| La familia ve un resultado privado | "Hay un resultado nuevo (privado)." |
| Espera estimada | "Es un estimado. Puede cambiar si llegan casos más graves. Si se siente peor, avise en recepción." |
| Mensaje a la enfermera | "Si es una emergencia o se siente peor, avise al personal de inmediato. Este mensaje no es para urgencias." |
| Quitar el acceso a un familiar | "Acceso de {nombre} retirado de inmediato." |
| Opt-out | "Usted puede decidir no compartir su información con otros proveedores por la red de salud." |
